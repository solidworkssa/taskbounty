# TaskBounty

Decentralized task marketplace with crypto bounties.

## Features
- Multi-chain support (Base & Stacks)
- Secure Contract Logic
- React/Next.js Frontend

## Contracts
- Base: `contracts/base/src/TaskBounty.sol`
- Stacks: `contracts/stacks/contracts/taskbounty.clar`

## Setup
```bash
pnpm install
pnpm dev
```
